# store-management-system

Monorepo containing clients and backend service implementations for the Store Management System:

- `fastify-server`: Fastify + TypeScript backend service (Stage 1 Foundation implemented)
- `express-server`: Express backend service
- `nest-server`: NestJS backend service
- `react-client`: React web client
- `angular-client`: Angular web client
- `vue-client`: Vue web client
